# BotFather owner checklist

After task `02`:

- set name, description, about text and canonical avatar;
- set private-chat commands from runtime source of truth;
- set menu button/Main Mini App URL;
- verify domain/Web App configuration;
- verify privacy/support links;
- test `/start`, `/app`, `/support`, `/settings`, `/help`, `/privacy`;
- do not configure `/news` before post-release news work;
- do not rotate token without explicit reason.
