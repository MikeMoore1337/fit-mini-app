# Backlog v6 changelog

## Product decisions

- Trainer mode is enabled directly; beta application/review queue removed.
- TMA knowledge library removed; long-form content remains Public Web.
- Full AI block moved after release.
- Demo Mode reduced from seven tasks to two curated tasks.
- Root Admin simplified; delegated admins moved after release.
- Added release-critical UX tasks for Today/week context, fast nutrition logging, workout completion summary and training preferences.
- Weekly Check-in and adaptive calories merged into one user flow.
- Nutrition reports and global report share the Progress information architecture.
- Added real-user usability validation checkpoint before production readiness.
- Telegram bot core remains a separate parallel release archive; news/digest moved post-release.
