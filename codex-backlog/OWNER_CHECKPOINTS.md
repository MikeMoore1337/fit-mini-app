# Owner checkpoints - release backlog v10

## Task 49B - visual directions review

Owner receives current Design V2 baseline plus three new cross-surface directions. This is review only, not approval.

## Task 49C - direction selection

Owner must provide one explicit token:

- `KEEP_V2_UNCHANGED`;
- `APPROVE_V2_1_REFINEMENT` with exact scope;
- `APPROVE_DIRECTION_A/B/C`;
- `APPROVE_EXPLICIT_HYBRID` with exact compatible scope;
- `REJECT_ALL_AND_REBRIEF`.

Without the token the backlog stops.

## Task 49D - specification approval

Required only for V2.1/new direction/hybrid. Owner approves or rejects final responsive specification before pilot.

## Task 49E - pilot validation

Owner manually checks at least one desktop browser and one physical phone. Telegram Android/iOS observations are recorded separately and only when actually tested.

## Task 49F - final approval

Owner provides a final explicit token. No silent or inferred approval.

## Task 49G - design source closure

Owner verifies that the active source matches the final decision. Only after this task may `50A` start.

## Task 50A - Mobile/TMA foundation

Mocked TMA coverage is not real-device validation. Limitations are recorded honestly.

## Task 69 - Demo

Owner verifies the three curated scenarios separately on Mobile Web and available Telegram clients.

## Task 70 - Trainer mode

Owner confirms wording for immediate activation and absence of verified-professional implications.

## Task 72 - TMA hardening

Owner reviews the real-device matrix and accepts any unverified client limitation explicitly.

## Task 73 - Landing

Owner approves factual screenshots, desktop/mobile composition, Mobile Web/TMA representation and final value proposition according to `ACTIVE_DESIGN_SOURCE.md`.

## Task 77 - Usability validation

Codex prepares and analyzes only real observations supplied by owner/participants. No fabricated sessions or metrics.

## Task 79 - Release

Owner decides go/no-go from factual design, usability, operational, Mobile Web and Telegram evidence.
