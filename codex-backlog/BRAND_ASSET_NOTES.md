# Brand assets - canonical reference

Для первого релиза визуальный источник истины по логотипу - файл:

`references/brand/your-fitness-coach-logo-reference-light-dark.png`

Верхняя половина показывает вариант для светлой темы, нижняя - для тёмной.

## Что считать утверждённым

- знак с объединёнными мотивами `Y` / `C` и штанги;
- лаймово-зелёный акцент;
- полный логотип с надписью `YOUR FITNESS COACH`;
- для светлой темы основной нейтральный цвет знака/надписи тёмный;
- для тёмной темы основной нейтральный цвет знака/надписи светлый.

Референс - растровый визуальный образец, а не production asset. Белый/тёмный фон, свечение и поля изображения не являются частью логотипа.

## Production requirements

Production-логотип должен быть заново собран как чистый SVG с прозрачным фоном. Нельзя использовать сам PNG как основной логотип и нельзя просто вставлять его внутрь SVG.

Нужны как минимум:

- полный SVG для светлой темы;
- полный SVG для тёмной темы;
- отдельный SVG-знак без надписи для favicon/app icon use cases;
- favicon, который остаётся читаемым на 16x16 и 32x32.

Favicon не содержит надпись `YOUR FITNESS COACH`. Для малого размера разрешено аккуратно упростить мелкие детали и увеличить отрицательные пространства, если это необходимо для читаемости, но характер знака должен сохраниться.

Не создавать альтернативный логотип, новую монограмму или другую цветовую концепцию без отдельного решения владельца проекта.
