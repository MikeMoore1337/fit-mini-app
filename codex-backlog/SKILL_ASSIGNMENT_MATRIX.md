# Матрица roles/skills для release backlog v11

Tasks `00-55` завершены и не переигрываются. Их task-файлы находятся в `tasks/done/`; строки `49B1-55` ниже сохранены как историческая сводка. Текущий и pending scope начинается с `56`.

Правила:

- `Рекомендуемые skills` - core skills primary role, открыть в начале task.
- `Условные skills` - не открывать заранее; подключать только при подтверждённом trigger.
- `Дополнительные роли lifecycle` - точный маршрут, а не рекомендация добавить ещё роли.
- Для code/diff review base skill - `$code-reviewer`, для QA - `$qa-engineer`; non-code decision review не загружает `$code-reviewer` автоматически.
- Task-файл остаётся source of truth при расхождении с этой сводкой.
