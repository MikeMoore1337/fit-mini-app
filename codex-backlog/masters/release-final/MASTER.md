# Your Fitness Coach — final pre-release master

## Product definition
YFC is a unified fitness system:
- nutrition;
- strength/cardio training;
- programs and progression;
- body measurements/progress;
- adherence/check-ins;
- trainer workflows;
- reviewed knowledge;
- deterministic analytics;
- personal AI Coach on top.

## Core principles
1. The app is useful without AI.
2. Deterministic calculations stay authoritative.
3. AI reads current authenticated user data through bounded tools.
4. No photo/image body analysis in first release.
5. No social-network scope before user evidence.
6. No autonomous AI writes in first release.
7. Advanced features use progressive disclosure.
8. Release scope freezes after task 92.

## First-release differentiation
Not "another workout logger" and not "ChatGPT in a fitness app":
YFC connects food + training + body progress + adherence + trainer + knowledge,
then lets Coach explain the user's own data.

## Final gaps intentionally closed
- progressive first-run onboarding;
- deterministic load progression guidance;
- unified reminders/notifications;
- account data export/deletion;
- manual cardio gap closure;
- operational production readiness.
