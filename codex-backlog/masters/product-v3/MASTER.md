# Product v3 master

Core value: `nutrition + training + body measurements + adherence + trainer + knowledge + unified analytics`.

AI Coach is an optional read-only intelligence layer built only after the core product is complete.

Target Coach: personal assistant over the authenticated user's own data, capable of explaining nutrition, today's workout, exercise progression, RIR, muscle exposure, check-ins, weight/anthropometry trends and stable preferences. It must show evidence/limitations and never use client/other-user data in personal context.

Explicitly no photo/image analysis.
