# Политика юридических источников для `$ru-legal-risk`

Дата подготовки baseline: 2026-08-28.

Этот файл не является «замороженной базой права». Он задаёт метод проверки. Перед каждым существенным аудитом нужно перепроверять действующие редакции.

## Приоритет источников

1. Официальный интернет-портал правовой информации - `https://publication.pravo.gov.ru/`.
2. Официальные сайты компетентных органов - Роскомнадзор, ФАС, Роспотребнадзор, ФНС и др.
3. Консолидированные правовые системы - `https://www.consultant.ru/`, `https://www.garant.ru/`.
4. Официальные судебные акты и разъяснения.
5. Вторичные статьи - только для поиска направления, не как единственное основание finding.

## Минимальный набор нормативных поверхностей YFC

Проверять только когда применимо к фактической функции.

| Область | Базовый акт / направление |
|---|---|
| Персональные данные | Федеральный закон N 152-ФЗ «О персональных данных» |
| Локализация/трансграничная передача | 152-ФЗ, в частности ст. 12 и ч. 5 ст. 18 |
| Специальные категории / здоровье | 152-ФЗ, ст. 10 |
| Согласия | 152-ФЗ, ст. 9 и специальные требования по конкретной категории |
| Уведомление оператора | 152-ФЗ, ст. 22 |
| Рекомендательные технологии | Федеральный закон N 149-ФЗ, ст. 10.2-2 |
| Права потребителей | Закон РФ N 2300-1 «О защите прав потребителей» |
| Договорная ответственность | ГК РФ, применимые главы/статьи по фактическим отношениям |
| Интернет-реклама | Федеральный закон N 38-ФЗ «О рекламе» |
| Medical boundary | Федеральный закон N 323-ФЗ «Об основах охраны здоровья граждан...» и лицензирование, если применимо |
| Платежи/чеки | N 54-ФЗ и/или режим НПД/иные налоговые требования - по статусу владельца и модели оплаты |
| Дети | N 436-ФЗ и другие нормы по фактической аудитории/контенту/ПД |
| Авторские права | часть IV ГК РФ и лицензии конкретных источников/библиотек |

## Как фиксировать источник в finding

```text
Legal basis checked:
- Act: 152-ФЗ
- Provision: ст. 18 ч. 5
- Revision/status: verified current on 2026-08-28
- Source: <URL>
- Interpretation confidence: HIGH
```

Если действующая редакция или дата вступления изменения не подтверждены:

```text
CONFIDENCE: LOW
LEGAL_COUNSEL_REQUIRED: YES (если вопрос существенный)
```

## Изменения права

При наличии будущих изменений обязательно разделяй:

- `CURRENT_REQUIREMENT` - действует сейчас;
- `FUTURE_REQUIREMENT` - вступит позже;
- `EFFECTIVE_DATE`;
- нужна ли подготовка продукта заранее.

Не выдавай будущую норму за действующую.
